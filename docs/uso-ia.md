# Uso de IA

Se utilizó ChatGPT/Codex como apoyo durante el desarrollo de MiniBlog.

| Paso | Solicitud o prompt | Cómo se utilizó |
|---|---|---|
| Planificación | «Ayúdame a proponer un plan de acción» a partir de la consigna. | Organizar requisitos y dividir el trabajo en etapas. |
| Implementación | Solicitudes sucesivas para continuar con SQL, conexión y endpoints. | Obtener ejemplos de código y explicaciones; implementarlos y probarlos paso a paso. |
| Correcciones | Compartir errores y capturas de la terminal. | Identificar imports faltantes, archivos mal ubicados, IDs fuera de rango e indentación YAML. |
| Pruebas | Continuar con pruebas automatizadas de la API. | Preparar pruebas con Supertest y pruebas de persistencia en una base separada. |
| Documentación | Completar README y OpenAPI. | Redactar instrucciones y describir las 11 operaciones de la API. |

Las solicitudes de la tabla resumen el trabajo realizado; solo la primera incluye un fragmento textual del prompt. El código sugerido se comprobó mediante consultas SQL, peticiones HTTP, Swagger y pruebas automatizadas. Codex también realizó algunas correcciones y ediciones directamente en los archivos.
